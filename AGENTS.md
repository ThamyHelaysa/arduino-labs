## Language

Write everything in English, even where existing files use Portuguese:

- Code: identifiers, comments, file names, user-facing messages.
- Docs: READMEs, glossaries, ADRs, issues and specs.
- Version control: commit messages, branch names, PR titles and descriptions.

The Portuguese triage labels in `projects/painel` are the one exception.

## Authorship

Credit only human authors in commits and pull requests:

- Commit messages end without a `Co-Authored-By` trailer naming Claude or another LLM.
- PR titles and descriptions leave out attribution footers and any mention of Claude or another LLM.
